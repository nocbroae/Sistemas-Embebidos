# OLED_RPI_ESP32

Repositorio de prácticas de Sistemas Embebidos Aplicados a Móviles usando pantallas OLED SSD1306 con:

- Raspberry Pi 3
- ESP32 con MicroPython

## Contenido

### Raspberry Pi
Prácticas usando:
- Python 3
- luma.oled
- Pillow
- I2C

### ESP32
Prácticas usando:
- MicroPython
- ssd1306.py
- machine.I2C
- FrameBuffer
